# Invoice System - Quick Reference

## User Journey

### For Admin/Owner:

1. **Complete a Booking:**
   - Go to active booking → Click "Return Vehicle" button
   - Enter closing odometer reading
   - Add any damages with photos
   - Enter deposit deduction amount (e.g., ₹500 for damages)
   - Choose "Generate Invoice" or "Generate Later"

2. **Generate Invoice:**
   - After booking is Completed, click the gray FileText icon
   - Review invoice details in dialog
   - Click "Generate Invoice" button
   - Invoice number auto-generated (e.g., INV-25260001)
   - Button turns green ✓

3. **View Invoice:**
   - Click the green FileText icon on any completed booking
   - View invoice details (read-only)
   - Optional: Send via WhatsApp

4. **Send Invoice:**
   - In invoice view dialog, click "Send via WhatsApp"
   - WhatsApp opens with pre-filled message
   - Booking marked as "Invoice Sent"

### For Staff:

- **Cannot generate invoices** (Admin only)
- Can view completed bookings but no invoice button appears
- Cannot edit/delete bookings with invoices

## Invoice Number Format

**Pattern:** `INV-YYMM-XXXX`

**Examples:**
- `INV-25260001` → FY 2025-26, Invoice #1
- `INV-25260099` → FY 2025-26, Invoice #99
- `INV-26270001` → FY 2026-27, Invoice #1 (resets April 1)

**Financial Year:**
- January-March: Previous calendar year
- April-December: Current calendar year

## Invoice Contents

### Header:
- Shop name, address, phone (from Settings)
- Invoice number
- Generation date

### Customer Details:
- Name (snapshot at generation time)
- Phone (snapshot at generation time)

### Vehicle Details:
- Vehicle name, type icon, reg number
- Price per day
- Rental period (start to end date/time)

### Financial Summary:
- Rent Amount: `₹{booking.rent}`
- Security Deposit: `₹{booking.deposit}`
- Deposit Deduction: `-₹{booking.depositDeduction}` (in red)
- Deposit Refund: `₹{deposit - depositDeduction}` (in green)
- **Total Payable:** `₹{rent - depositDeduction}` (bold)

### Footer:
- Generated by: User name
- Generated at: Date/time

## Important Rules

### ✅ Can Generate Invoice When:
- Booking status is 'Completed'
- User is Admin/Owner
- Deposit deduction has been entered
- Invoice doesn't already exist

### ❌ Cannot Generate Invoice When:
- Booking not completed
- User is Staff
- Deposit deduction not set
- Invoice already exists

### 🔒 Locked After Invoice:
- **Cannot edit** booking details
- **Cannot delete** booking
- **Cannot change** status
- **Cannot modify** amounts
- Invoice is **immutable** (cannot edit/delete)

## Error Messages

| Error | Reason | Solution |
|-------|--------|----------|
| "Missing Deposit Deduction" | Trying to generate invoice without setting deposit deduction | Go through Return Flow first |
| "Only completed bookings can have invoices generated" | Trying to generate for non-completed booking | Complete the booking first |
| "Invoice already exists for this booking" | Trying to generate duplicate invoice | Use "View Invoice" instead |
| "Customer or vehicles not found" | Data integrity issue | Check booking data |

## Troubleshooting

### Invoice button not showing?
- Check booking status (must be 'Completed')
- Check user role (must be Admin/Owner)
- Refresh page

### Cannot generate invoice?
- Ensure deposit deduction is set
- Ensure booking is completed
- Check console for errors

### Invoice disappeared?
- Clear browser cache/localStorage = data loss
- No recovery (local-only system)
- Always backup before clearing cache

### Wrong invoice number?
- Counter increments on each generation
- Cannot change once generated
- Cannot reset counter manually

## Tips

1. **Always set deposit deduction** before generating invoice
2. **Review amounts** in dialog before generating
3. **Cannot undo** invoice generation
4. **Green icon** = Already generated
5. **Send WhatsApp** doesn't send automatically - opens WhatsApp app
6. **Invoice snapshots** customer/vehicle data at generation time
7. **Financial year** changes automatically on April 1st
8. **Counter increments** even if generation fails (no rollback)

## Compliance Note

This system is designed for **LOCAL MVP** only:
- No tax calculations (user responsible for GST)
- No PDF generation (WhatsApp message only)
- No audit trail (invoice immutable but no history)
- No multi-user conflicts (single device)
- No cloud backup (local only)

For production use with multiple users, backend integration would be required.

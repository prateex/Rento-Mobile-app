## PART 2: CRITICAL BUG AUDIT

### BUG #1: vehicles.vehicle_type REFERENCED BUT DOES NOT EXIST
**Severity:** CRITICAL - Application runtime error  
**Location:** `backend/client/src/pages/Bikes.tsx` line 452  
**Code:**
```typescript
type: (row.vehicle_type as any) || bikeData.type,  // ❌ row.vehicle_type is UNDEFINED
```

**Root Cause:**
- Database schema has only `type` column (vehicle_type ENUM)
- No column named `vehicle_type` exists
- Frontend tries to read non-existent column
- Fallback to `bikeData.type` masks the issue

**Fix Applied:**
```typescript
type: row.type,  // ✅ Correct - reads actual DB column
```

**Impact:**
- BEFORE: Vehicle type silently falls back to user input, correct by accident
- AFTER: Vehicle type reads directly from DB, guaranteed correct

**Status:** ✅ FIXED (Commit: Bikes.tsx line 452)

## PART 5: TRIGGER AND AUTO-NUMBERING VERIFICATION

### ✅ Booking Numbering (BK0001 format)
- **Trigger:** `trigger_set_booking_number()` on BEFORE INSERT
- **Function:** `generate_booking_number(p_shop_id UUID)` returns TEXT
- **Counter Table:** `booking_number_counters` (shop_id as PK)
- **Format:** 'BK' || LPAD(counter, 4, '0')
- **Status:** ✅ Correct

### ✅ Invoice Numbering (INV-25-26-0001 format)
- **Trigger:** `trigger_set_invoice_number()` on BEFORE INSERT OR UPDATE
- **Function:** `generate_invoice_number(p_shop_id UUID, p_ts TIMESTAMPTZ)` returns TEXT
- **Counter Table:** `invoice_number_counters` (shop_id, financial_year composite key)
- **Financial Year:** Calculated as FY-YY format (e.g., '25-26' for 2025-2026)
- **Format:** 'INV-' || fy || '-' || LPAD(counter, 4, '0')
- **Trigger Logic:** Only generates when status = 'Completed'
- **Status:** ✅ Correct

### ✅ Customer Numbering (CUST0001 format)
- **Trigger:** `trigger_set_customer_number()` on BEFORE INSERT
- **Function:** `generate_customer_number(p_shop_id UUID)` returns TEXT
- **Counter Table:** `customer_sequences` (shop_id as unique key)
- **Format:** 'CUST' || LPAD(counter, 4, '0')
- **Status:** ✅ Correct

### ✅ User Tracking (created_by auto-population)
- **Trigger (vehicles):** `set_vehicles_created_by()` on BEFORE INSERT
- **Trigger (customers):** `set_customers_created_by()` on BEFORE INSERT
- **Trigger (bookings):** `set_bookings_created_by()` on BEFORE INSERT

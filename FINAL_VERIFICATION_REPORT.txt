## 7. TECHNICAL DETAILS

### Fix Implementation Pattern
```typescript
// BEFORE (❌ WRONG)
const { data, error } = await supabase
  .from('payments')
  .insert({
    recorded_by: uid  // ❌ uid is auth.users.id, not users.id
  });

// AFTER (✅ CORRECT)
const { data: userRecords } = await supabase
  .from('users')
  .select('id')
  .eq('auth_id', uid);  // Look up the users table ID
  
const userId = userRecords[0].id;  // ✅ Now using users.id

const { data, error } = await supabase
  .from('payments')
  .insert({
    recorded_by: userId  // ✅ userId is users.id
  });
```

### Schema Constraints Enforced
```sql
-- payments.recorded_by MUST reference users(id)
ALTER TABLE payments ADD CONSTRAINT payments_recorded_by_fkey 
  FOREIGN KEY (recorded_by) REFERENCES users(id);

-- damages.reported_by MUST reference users(id)
ALTER TABLE damages ADD CONSTRAINT damages_reported_by_fkey 
  FOREIGN KEY (reported_by) REFERENCES users(id);

-- All other foreign keys already correct
```

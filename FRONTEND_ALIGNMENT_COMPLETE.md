### 4. **Bikes.tsx** - Handle Null Vehicle Names in Display
**File**: [backend/client/src/pages/Bikes.tsx](backend/client/src/pages/Bikes.tsx)

#### Before:
```typescript
name: row.name || '',  // Empty string if null
```

#### After:
```typescript
// Fallback name: use brand+model or registration_number if name is null
const displayName = row.name || 
  `${row.brand || ''} ${row.model || ''}`.trim() || 
  row.registration_number || 
  'Unknown Vehicle';
  
name: displayName,
```

**What changed:**
- ✅ Smart fallback hierarchy:
  1. Use `name` if present
  2. Else use `brand model`
  3. Else use `registration_number`
  4. Else use `'Unknown Vehicle'`
